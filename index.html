How this game is built

Frogger in NYC has two layers. The core rules engine (js/) is owned by a small team and defines how the game plays for everyone. The street layer (streets/*.json) is open — anyone can design a block with the editor and submit it. Every street is validated against the core schema before it loads. See docs/GOVERNANCE.md.
